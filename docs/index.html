7 Edge-Case Verification Categories

Every test plan balances normal behavior against adversarial inputs and business-logic violations.

happy_path

Baseline Contract

Verifies valid payloads return expected 2xx status codes and response shapes.

missing_field

Missing Required Fields

Omits required parameters one by one to catch unhandled 500s.

type_validation

Type Coercion

Sends strings for numbers, booleans for objects, and unexpected nulls.

boundary

Boundary Limits

Probes zero, negative-one, and extreme numeric thresholds.

business_rule

Plain-English Invariants

Targets domain rules like non-positive quantities or negative unit prices.

malformed_input

Malformed Payloads

Tests empty bodies, unexpected structures, and invalid inputs.

inconsistent_data

Semantic Contradictions

Detects conflicting values and flags ambiguous contracts for human review.

Where APIForge fits

Built for developers who want to know what weird inputs break their backend—without writing test boilerplate first.
